# JCASM

The JCASM (JoltCore Assembler) is a small piece of software that allows you to translate human-readable assembly source code into machine-readable formats. To make programming for the JC16 as easy as possible, it provides features known from high-level languages (like preprocessor directives and named jumps) and tries to perform as much work for the programmer as possible. It is capable of performing basic optimization and templating using definitions. The behavior of the assembler can be altered using command-line flags.
